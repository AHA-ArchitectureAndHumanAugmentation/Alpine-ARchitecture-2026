## Contents

- Rhino (`.3dm`) and Grasshopper (`.gh`) files that were used during class.
- Support material, tutorials.
- GeoViewer, an AR visualization app developed in Unity using COMPAS XR.

## How to download

#### A. Without installing Git
Click on `Code` > `Download ZIP` and unpack it:
<img width="982" height="483" alt="github-download-zip" src="https://github.com/user-attachments/assets/b4a1508c-cf48-4496-b53c-12327a9d9324" />

#### B. With GitHub Desktop:
1. Click `File` > `Clone Repository`
2. Select `URL` and put this repo's URL: `https://github.com/AHA-ArchitectureAndHumanAugmentation/Alpine-ARchitecture-2026.git`. Click **Clone**.
<img width="962" height="661" alt="github-desktop-clone-r" src="https://github.com/user-attachments/assets/0edf7d08-15bc-4a74-8a57-fdfacd69ff81" />

## How to open the Unity Project

- Download & Install Unity Hub. 
- Download & Install the Unity version for this project (`6000.0.79f1` - [Download Unity from Archive](https://unity.com/releases/editor/archive))
- In Hub, click Add > Add project from disk
 <img width="212" height="114" alt="image" src="https://github.com/user-attachments/assets/e2f8565f-f51c-4284-8da5-976733c2bfb3" />
 
- You should be then able to see the project and its version. If the right Unity version is not installed, it will have a warning sign next to it. 
<img width="1285" height="90" alt="image" src="https://github.com/user-attachments/assets/0d85d68d-f3f4-477e-8abb-340d7d234802" />

- You can now open the project.

> [!Note]
> It will take some time the first time you launch it, because it generates the Library and other folders. Make sure you have sufficient time that you don't interrupt this process.
